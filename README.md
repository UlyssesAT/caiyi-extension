# 采邑（Caiyi）

> 轻量、无干扰的网页批注、截图标注与多维视觉归档工具。

**当前版本：v1.0.0**  
**平台：Chrome / Chromium（Manifest V3）**  
**作者：[擒纵漫步 (EscapePace)](https://github.com/UlyssesAT)**  
**许可证：GPL-3.0**

## 项目简介

**采邑（Caiyi）** 是一款运行在浏览器中的网页批注与视觉归档插件。它的目标是在尽量不打扰阅读的前提下，让用户直接在原网页上完成高亮、标点、截图、批注与导出。工具在不使用时尽可能隐形，只在需要时出现。

名字取自中国古代君主、诸侯分封领地的用词，即被赏赐的分封领地，它十分契合本插件的设计理念：在信息洪流中圈定一小块属于自己的区域，采拾、标记并保存真正值得留下的内容与思绪。

## 核心功能

### 文本涂色

支持直接在网页中选择文字进行高亮。

高亮系统不是简单调用原生 `surroundContents()`，而是基于 `TreeWalker` 对跨标签文本节点进行切片处理，因此能够适应更复杂的 DOM 结构，并降低破坏宿主网页结构的风险。

### 原文标点

可在网页原文旁添加几何标点，包括：微点、序号、三角、菱形、星形、方块、旗标。其中序号模式支持自动递增。

标点尽可能与原文节点保持真实位置关联，而不是简单漂浮在页面绝对坐标上。

### 区域截图

支持在当前视口中拖拽框选区域并生成截图。截图可以：

- 作为批注卡片内容保存
- 显示缩略图
- 单独下载原图
- 参与后续摘录与视觉归档

### 批注卡片

网页中的高亮、标点和截图可以对应到右侧批注卡片。

卡片采用视口实时投影机制，会根据原文实际位置动态调整，尽可能保持批注与原文之间的视觉对应关系。

### 多格式导出

- **导出摘录**：提取带批注的段落，并将原文与批注重新排版为左右双栏图卷
- **导出长图**：逐屏捕获网页并拼接成长图
- **导出宫图**：将多个视口切片重新排版为画廊式网格图
- **Markdown**：导出 `.md`
- **Word**：导出 Word 兼容 HTML 文档

## 交互设计

采邑强调低存在感。

默认常驻状态不是传统的大型悬浮按钮，而是一个低对比度的微型启动条。鼠标靠近后，它才展开为完整的“采邑”操作胶囊。

启动器支持拖拽，其位置可以跨会话保存。

批注卡片则尽量限制在网页右侧区域，避免直接侵入正文阅读空间。

## 技术栈

项目保持零构建依赖：

- Vanilla JavaScript（ES6+）
- CSS3
- HTML5 Canvas
- Chrome Extension API
- Manifest V3

不依赖：

- React
- Vue
- npm runtime dependencies
- webpack
- Vite
- 第三方 UI 框架

因此可以直接加载源码目录进行开发与调试。

## 安装

### 下载压缩包安装

1. 在本仓库下载最新版本的插件压缩包（`.zip`）。
2. 将压缩包解压到一个固定目录。
3. 打开 Chrome：

```text
chrome://extensions/
```

Edge：

```text
edge://extensions/
```

4. 开启“开发者模式”。
5. 点击“加载已解压的扩展程序”。
6. 选择刚刚解压、且包含 `manifest.json` 的插件目录。

安装完成后刷新需要使用采邑的网页。

## 隐私

v1.0.0 采用本地优先设计。

根据当前项目架构：

- 不依赖远程 API 才能完成核心批注功能
- 不集成广告 SDK
- 不集成第三方分析 SDK
- 未设计将网页正文或批注内容主动上传服务器的流程
- 工具状态主要保存在浏览器本地
- 截图、Canvas 合成与文档生成主要在本地完成
- 文件下载由用户主动触发

浏览器扩展本身具有读取当前网页 DOM 的能力，这是高亮、标点和截图等功能正常工作的必要条件。

## 设计原则

采邑当前开发遵循几条核心原则：

1. **不工作时尽可能隐藏。**
2. **批注必须与原文位置保持稳定关联。**
3. **不得为了批注界面而破坏宿主网页原有排版。**
4. **视觉归档不是简单截图，而是重新组织信息。**
5. **尽量使用浏览器原生能力，减少依赖和构建复杂度。**
6. **导出结果本身也应具有可阅读、可保存、可展示的视觉质量。**
